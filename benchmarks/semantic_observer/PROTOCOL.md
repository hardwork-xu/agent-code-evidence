# Prospective finite binding-observation protocol

Frozen before evaluator task identities are unsealed and before target execution.
This is a within-study prospective convenience panel, not an independent external
replication, an unexposed-to-pretraining claim, or mature research.

## Question and independent measurement

Can bounded source-derived literal global-value hypotheses agree with independently
observed pre-op global bindings while retaining useful coverage on actual bug-fix tasks?
The observer imports no resolver. It verifies compiled code against exact source bytes
and records CPython 3.12 LOAD_GLOBAL bindings before instruction execution. This does
not prove the operand was consumed, full program semantics, or necessary context.
Native code, signals, transient threads, hostile tracing, and source changes restored
between checks remain outside its guarantee. Exact primitive types only; unsupported
values, builtins, missing names, dropped events and ambiguous alignments remain visible.

The product's resolved source witness does not promise an immutable runtime value.
A mismatching derived value hypothesis refutes that experimental interpretation;
it does not automatically establish stale whole-graph certification or a product bug.

## Frozen methods and budgets

- `currentfresh`: persistent module-summary indexing with current graph rebuild.
- `whole_guard`: the same indexing with whole-corpus equality reuse.
- `selective`: actual bounded read-set reuse.
- `always_abstain`: an explicit zero-coverage control.

Use each real GraphSession policy with separate identically configured caches. Select
at most 32 function identities from the union of both production snapshots, ordered by
SHA256 of path/qualified-name, independent of traces, tests and graph acceptance.
All production Python source is supplied; maximum graph depth 4 and nodes 256.
Only real resolved read edges to literal constants yield primitive value hypotheses.
Three fresh-cache repetitions, rotated method order, no warmup. Capture and replay
include projection; common source loading/discovery/hash cost is reported separately.
Timings are descriptive and repetitions are not independent tasks. No causal speedup
claim or model-quality claim is authorized by this experiment.

For each role run plain and observed in separate processes; alternate order by task
index. Run serially. Execution caps: 300 CPU seconds, 600 wall seconds, sampled RSS
3072 MiB, 20000 distinct observation records. Keep repeated-event counts after
aggregation, and mark any dropped record events incomplete. Native memory is not an
OS-enforced sandbox; the controller monitors its child and terminates its own group.
Dependency versions and reviewed plugins/warning rules are explicit. Network, external
process and Python thread launches remain denied. All source bytes must match before
and after. Static predictions for all tasks must be sealed before the first unseen
SUT starts. Implementation SHA bindings are rechecked for each condition.

## Qualification and scoring fixed before outcomes

Require real calls, exact selected-item and phase-outcome parity, no missing selectors,
no collection failures, no denied operations, source identity, observer integrity and
complete observation. Invalid roles remain in all-task denominators and have no
qualified semantic accuracy. Preserve their raw diagnostic observations.

Align by exact path, source SHA, runtime qualified owner and global name, plus complete
opcode position contained in a unique declaring function span. This is owner-span
alignment, not an exact static occurrence mapping. Distinct hypotheses are ambiguous
and abstain. The site identity retains code signature, bytecode offset and position.
A site matches only if every observed primitive value agrees with its single supported
hypothesis. Mixed values and every contradiction count. Event-weighted metrics are
secondary; site/task units are primary. Whole-graph completeness is separate.

Finite utility gate, separately for each nontrivial method:
1. All eight selected task pairs have both execution-qualified roles and stable
   predictions across repeats.
2. Zero observed mismatching accepted sites (finite evidence, not a risk bound).
3. Mean task site coverage >= 0.05 over all eight selected tasks, counting unqualified
   tasks and zero eligible denominators as zero coverage.
4. At least four of eight tasks have a supported accepted site.

The primitive site denominator includes all observed supported module-global sites,
including unselected owners and graph refusals. Report all other observation statuses
separately. Zero acceptances imply undefined accuracy, never 100% correctness.
A passed gate would support only finite primitive-binding agreement; C4 full semantic
freshness, C6 coding-agent benefit, novelty and maturity remain unestablished.

## Preservation and publication

Save every condition config, command, runtime/dependency/source identity, phase report,
raw stdout/stderr, closure, observation and prediction before analysis. Private absolute
paths/raw logs stay outside Git. Publish only a reviewed, hash-linked projection with
original source URLs, licenses, exact pins, all failures, methods and denominators.
Changes after exposure require a new explicitly labelled development amendment; the
original primary record and all negative results remain unchanged.
