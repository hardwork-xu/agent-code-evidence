# 前瞻性有限全局绑定观测协议

本协议在评估方解封任务身份、执行目标程序之前冻结。这是研究内部的前瞻性方便样本，
不等于外部独立复现、模型预训练未见证明或成熟成果。

问题：源码字面量产生的全局值假设，能否与独立执行观测一致并保留有用覆盖？
观测器不导入解析器，按源码字节编译认证 CPython 3.12 代码对象，在 LOAD_GLOBAL
执行前记录绑定；不证明操作数已被消费、完整程序语义或必要上下文。
原生代码、信号、瞬时线程、主动篡改跟踪和检查间恢复源码仍有盲区。
仅支持精确 primitive 类型，其他值、内置名、缺失名、丢弃和歧义均保留。
产品的源码见证不承诺运行时不可变；失配只能反驳这个派生实验假设，不能自动称整图 stale。

固定 4 个仓库的 8 个真实已合并修复任务，按执行前规则排除历史研究中出现过的仓库。
任务清单 SHA256 为 `68b002c156ad9d9119c78fa569925e1a0e0d1459d98fb3c2877ab5b50f894569`；
规则 v2 SHA256 为 `93fd2d6ed91bfdb32eff5e117a80f5ccff0162c5a4ffbc2d501acc6ca07728ba`。
冻结后不替换准备、收集或资源失败任务。两角色均执行完整原改动测试模块及参数化；
base 生产代码配 fixed 原测试，fixed 使用修复后生产代码。没有生成修复、智能体成功率。

两个已暴露 yt-dlp 任务仅用于开发校准。8 条件均已闭合，4 角色的跟踪/非跟踪结果相同，
但依赖的 platform.architecture 系统探测被进程约束拦截，4/4 角色不具运行资格；保留原负面。

四方法为 currentfresh（持久模块摘要+当前图重建）、whole_guard（整库相等复用）、
selective（实际读取集复用）、always_abstain（零覆盖）。前三者独立同配置缓存，
两版本全部生产 Python 源码作为输入，函数身份并集按路径/限定名 SHA 排序，最多 32 个；
不依赖运行轨迹、测试结果或图是否接受。深度 4、节点 256，只从真实已解析读取边
生成字面量假设。3 次新缓存重复、轮换方法顺序、无预热。记录加载和公共准备成本，
capture/replay 含投影；时间只作描述，重复不增加独立任务数，不推导速度或模型收益。

每角色两个新进程，按任务索引交替观测顺序，全程串行。CPU 300 秒、墙钟 600 秒、
采样 RSS 3072 MiB、最多 20000 条不同观测记录；聚合保留全部次数，丢弃即不完整。
这不是操作系统安全沙箱。依赖版本、插件及 warning 规则显式固定；拒绝网络、
外部进程和 Python 新线程。前后核对全部源码，首个未见执行前封存全部静态预测。
每条件检查实现 SHA。

资格要求：真实调用、相同选中项和逐阶段结果、无缺失/收集失败/操作拦截、源码相同、
观测完整且有效。无资格角色保留原始诊断及全任务分母，无合格语义准确率。
按路径、源码 SHA、运行时限定 owner、全局名精确匹配，opcode 完整位置包含于唯一函数
声明跨度。此为 owner 跨度对齐，并非静态读取 occurrence 精确映射；歧义弃权。
site 保留代码签名、偏移和物理位置；只有其全部 primitive 观测均一致才算匹配，
混合值与每个矛盾保留。site/task 为主，event 为次，整图完整性另算。

每个非平凡方法的有限效用门槛，在结果之前固定：
1. 8/8 任务的两角色有运行资格，3 次静态预测一致。
2. 接受 site 的观测矛盾为零；不是总体风险界。
3. 按全部 8 任务平均的 site 覆盖率至少 0.05；无资格、零分母按覆盖零计。
4. 至少 4/8 任务具有一个受支持接受 site。

primitive 分母包括全部观测到的受支持模块全局 site，包括未选 owner、图拒绝；其他
状态另报。零接受准确率为未定义，不能写 100%。通过也只支持有限 primitive 绑定一致性，
不能建立 C4 完整语义 fresh、C6 智能体收益、新颖性或成熟成果。

保存所有配置、命令、源码/环境身份、逐阶段报告、日志、闭合状态、观测与预测。
私人绝对路径及原始终端日志在 Git 外；仅发布经审查的可关联摘要、来源、许可、固定版本、
全部失败和分母。暴露后的修改须单列开发修订，不替换主实验。
运行时来源：[CPython tracing](https://docs.python.org/3.12/library/sys.html#sys.settrace)、
[LOAD_GLOBAL](https://docs.python.org/3.12/library/dis.html#opcode-LOAD_GLOBAL)。
